# StockBase IMS1 — Inventory Management System

A terminal-based inventory management system built with Python and PostgreSQL. Designed for small businesses to manage products, record sales, track stock, and generate profit reports.

## Features

- Role-based access control (Manager & Cashier)
- Secure password hashing with bcrypt
- Real-time stock tracking on every sale
- Profit reporting per product
- Customer records with phone number tracking
- Anonymous sales support for walk-in customers
- Staff management (add, delete, change roles)

## Tech Stack

- Python 3
- PostgreSQL
- psycopg2
- bcrypt
